# Clawd Mochi · ESP32 桌宠（二创版）

一块巴掌大的 ESP32 桌面宠物：1.54 寸 240×240 屏幕上是一张会眨眼、会晃动的脸，设备自己开 WiFi 热点，手机浏览器连上去就能遥控。不用装 App、不用连家里的路由器、不接外网。

本项目是基于 MakerWorld 上开源模型 **Clawd Mochi** 的学习性二创，在原版「表情 / 时钟 / 终端 / 画板」的基础上，扩展了情绪、互动、主动互动、睡眠、日程、生日动画等模块，并重做了整套手机端控制页面。

- 原作页面：[Clawd Mochi 物理 ESP32 Claude 代码机箱物](https://makerworld.com.cn/zh/models/2295449-clawd-mochi-wu-li-esp32-claude-dai-ma-ji-xiang-wu)
- 完整的上手步骤和排障说明见 [桌宠使用说明书.md](桌宠使用说明书.md)

## 功能

**5 个屏幕画面**

| 画面 | 内容 |
|---|---|
| 正常眼睛 | 方块眼 + 左右晃动 + 眨眼（默认） |
| 开心挤眼 | `> <` 眼睛，一睁一闭 |
| Claude Code | 绿色终端界面，手机端输入框打字 |
| 画板 | 手机画，桌宠屏同步显示 |
| 时钟与日历 | 大字时间 + 日期 + 当月月历 |

**7 个功能页**

| 模块 | 说明 |
|---|---|
| 表情 | 16 张脸 + 7 种动画 + 锁定 / 复位 |
| 情绪 | 开心 / 精力 / 生气 / 难过 / 好奇 / 惊吓 / 害羞 七项情绪值，带衰减，并与表情联动 |
| 互动 | 单击 / 连击 / 过度戳 / 长按，事件驱动情绪变化 |
| 主动互动 | 长时间没人理会自己动一下（眨眼、打哈欠、发呆、张望…） |
| 睡眠与唤醒 | AWAKE / DROWSY / SLEEPING / WAKING 状态机，支持夜间判断 |
| 日程与纪念日 | 倒计时提醒（24h / 1h）+ 纪念日当天全屏庆祝 |
| 生日动画 | 240×240 像素场景：横幅、三层蛋糕、数字蜡烛、角色、气球彩带、中文对话框 |

另外还有屏幕背光开关、动画速度滑杆（1×–10×）、背景色 / 画笔颜色等设置。

## 硬件

| 元件 | 型号 |
|---|---|
| 主控 | ESP32-C3 Super Mini |
| 屏幕 | ST7789 1.54" 240×240（SPI） |
| 供电 | USB 5V（建议 5V 2A 充电头 + 短粗线） |

接线（屏幕 VCC 必须接 3.3V，接 5V 可能烧屏）：

| 屏幕 | ESP32-C3 |
|---|---|
| SDA / MOSI | GPIO 10 |
| SCL / SCK | GPIO 8 |
| RST | GPIO 2 |
| DC | GPIO 1 |
| CS | GPIO 4 |
| BL | GPIO 3 |
| VCC | 3V3 |
| GND | GND |

SPI 使用硬件总线：`SPI.begin(8, -1, 10, 4)`（SCK=8，MOSI=10，CS=4）。

## 编译与烧录

1. Arduino IDE 2.x，安装 **esp32** 开发板包（本项目在 3.3.11 下编译通过）。
2. 库管理器安装 **Adafruit GFX Library** 和 **Adafruit ST7789 Library**。
3. 打开 [clawd_mochi/clawd_mochi.ino](clawd_mochi/clawd_mochi.ino)，开发板选 **ESP32C3 Dev Module**。
4. 直接上传。

编译占用参考：Flash 1,291,417 B / 1,310,720 B（98%），全局变量 42,560 B（12%）。Flash 余量很小，加功能前先算空间。

## 使用

1. 通电，屏幕显示热点信息。
2. 手机连接 WiFi `ClaWD-Mochi`，密码 `clawd1234`。
3. 浏览器打开 `http://192.168.4.1`。
4. 点一次「时钟与日历」完成对时（每次断电重启后都要重新对一次）。

> 热点密码是公开的默认值，只适合在家 / 自己身边使用；它不连接外部网络，也不会上传数据。

## 已知限制

- **中文只覆盖生日对话框**：设备端只有 5×7 英文字库，整套中文点阵放不进剩下的 Flash，所以只给对话框做了 29 个字的 16×16 点阵，其余调试标题仍是英文。
- **断电不保存时间**：时钟依赖打开网页时同步手机时间，断电重启后需要重新打开一次页面。
- **生日动画吃内存**：整屏离屏画布约占 96 KB 堆，内存不足时会白屏，页面上的「▶ 推到桌宠屏幕」可以重新初始化。
- **供电敏感**：电压不稳会导致热点掉线或屏幕闪烁，串口日志里出现 `BROWNOUT` 基本就是供电问题。
